📚 Basic Logical Connectives

AND ( ∧ )

AND is true only when both statements are true.

Formula: P ∧ Q

Example: If P = True and Q = True, then P ∧ Q = True.

OR ( ∨ )

OR is true when at least one of the statements is true.

Formula: P ∨ Q

Example: If P = True and Q = False, then P ∨ Q = True.

NOT ( ¬ )

NOT reverses the truth value of a statement.

Formula: ¬P

Example: If P = True, then ¬P = False.

Implication ( → )

Implication is false only when P is true and Q is false.

Formula: P → Q

Example: If P = True and Q = False, then P → Q = False.

Biconditional ( ↔ )

Biconditional is true when both statements have the same truth value.

Formula: P ↔ Q

Example: If P = True and Q = True, then P ↔ Q = True.

XOR ( ⊕ )

XOR is true when exactly one statement is true.

Formula: P ⊕ Q

Example: If P = True and Q = False, then P ⊕ Q = True.

NAND ( ↑ )

NAND is the negation of the AND operation. It is false only when both statements are true.

Formula: P ↑ Q = ¬(P ∧ Q)

Example: If P = True and Q = True, then P ↑ Q = False.

NOR ( ↓ )

NOR is the negation of the OR operation. It is true only when both statements are false.

Formula: P ↓ Q = ¬(P ∨ Q)

Example: If P = False and Q = False, then P ↓ Q = True.
