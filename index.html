📚 Basic Logical Connectives

AND ( ∧ )

True only when both statements are true.

Example: P ∧ Q

OR ( ∨ )

True when at least one statement is true.

Example: P ∨ Q

NOT ( ¬ )

Reverses the truth value of a statement.

Example: ¬P

Implication ( → )

False only when P is true and Q is false.

Example: P → Q

Biconditional ( ↔ )

True when both statements have the same value.

Example: P ↔ Q

XOR ( ⊕ )

True when exactly one statement is true.

Example: P ⊕ Q
