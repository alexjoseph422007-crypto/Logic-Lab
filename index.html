📚 Basic Logical Connectives

AND Gate ( ∧ )

Rule: The output is 1 only if all inputs are 1. Otherwise, the output is 0.

Example: A car starts only when the key is turned AND the brake pedal is pressed. Both conditions must be satisfied for the car to start.

Formula: X = A ⋅ B

OR Gate ( ∨ )

Rule: The output is 1 if at least one input is 1. The output is 0 only when all inputs are 0.

Example: A security alarm activates when the door sensor OR window sensor detects an intrusion. Either sensor can activate the alarm.

Formula: X = A + B

NOT Gate ( ¬ )

Rule: The output is the opposite of the input. If the input is 1, the output is 0, and vice versa.

Example: An automatic street light turns ON when daylight is NOT detected. When daylight is detected, the light turns OFF.

Formula: X = ¬A

Implication ( → )

Rule: The output is 0 only when A is 1 and B is 0. In all other cases, the output is 1.

Example: If a student is present, their attendance should be recorded. The condition fails when the student is present but their attendance is not recorded.

Formula: X = A → B = ¬A + B

Biconditional ( ↔ )

Rule: The output is 1 when both inputs have the same value. It is 0 when the inputs are different.

Example: A security system grants access when two verification checks have matching results. If one check passes and the other fails, access is denied.

Formula: X = A ↔ B

XOR Gate ( ⊕ )

Rule: The output is 1 when exactly one input is 1. If both inputs are the same, the output is 0.

Example: A hallway light controlled by two switches changes its state when only one switch is activated.

Formula: X = A ⊕ B

NAND Gate ( ↑ )

Rule: The output is 0 only when all inputs are 1. For every other combination, the output is 1.

Example: In an industrial machine, the safety system stops the machine when both safety conditions are active. Otherwise, the machine remains enabled.

Formula: X = ¬(A ⋅ B)

NOR Gate ( ↓ )

Rule: The output is 1 only when all inputs are 0. If any input is 1, the output is 0.

Example: A traffic monitoring indicator remains active when neither sensor detects a vehicle. If either sensor detects a vehicle, the indicator turns OFF.

Formula: X = ¬(A + B)
