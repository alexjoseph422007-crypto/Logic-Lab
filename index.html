📚 Basic Logical Connectives

AND Gate ( ∧ )

Rule: The output is 1 only if all inputs are 1. Otherwise, the output is 0.

Example: Like two safety switches in a machine; both switch A and switch B must be turned on to run the motor.

Formula: X = A ⋅ B

OR Gate ( ∨ )

Rule: The output is 1 if at least one input is 1. The output is 0 only when all inputs are 0.

Example: A warning system has two sensors. If sensor A or sensor B detects danger, the warning alarm turns on.

Formula: X = A + B

NOT Gate ( ¬ )

Rule: The output is the opposite of the input. If the input is 1, the output is 0, and vice versa.

Example: An automatic light turns on when it detects that it is not daytime. If the daytime signal is 1, the light output is 0.

Formula: X = Ā

Implication ( → )

Rule: The output is 0 only when A is 1 and B is 0. In all other cases, the output is 1.

Example: If a student submits an assignment, then the system records the submission. The condition is violated when the assignment is submitted but the system fails to record it.

Formula: X = A → B = ¬A + B

Biconditional ( ↔ )

Rule: The output is 1 when both inputs have the same value. It is 0 when the inputs are different.

Example: A security system allows access when two authorization signals agree — both are valid or both are invalid.

Formula: X = A ↔ B

XOR Gate ( ⊕ )

Rule: The output is 1 when exactly one input is 1. If both inputs are the same, the output is 0.

Example: A hallway light can be controlled by two switches. The light is ON when exactly one switch is ON.

Formula: X = A ⊕ B

NAND Gate ( ↑ )

Rule: The output is 0 only when all inputs are 1. For all other input combinations, the output is 1.

Example: A machine stops only when both safety switches A and B are activated. Otherwise, the machine remains enabled.

Formula: X = ¬(A ⋅ B)

NOR Gate ( ↓ )

Rule: The output is 1 only when all inputs are 0. If any input is 1, the output is 0.

Example: An alarm system remains active only when neither sensor A nor sensor B detects movement.

Formula: X = ¬(A + B)
